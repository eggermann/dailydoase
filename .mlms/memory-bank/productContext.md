# Product Context

## Purpose

Create an audiovisual Glass Kaufhaus exhibition work from poster imagery, artist metadata, words, and the Shorty-Book generation pipeline.

## Users

Artist/operator and exhibition visitors.

## Core Value

Turn static exhibition material into a coherent warehouse/Kaufhaus television-trailer story with a stable, recognisable protagonist.

## Current Scope

First deterministic, no-live-camera video run from `lib/Plak-2_images/`.

## Non-Goals

Live visitor interaction, player redesign, and deployment.
