# Product Context

## Purpose

Turn a real Glas Kaufhaus visitor and the visible old department-store floor into a short, evolving semantic film.

## Users

- Exhibition visitors who become temporary protagonists.
- Artist/operator controlling words, style, rhythm, and model routing.

## Core Value

The work does not merely display generated video. It watches a real encounter, translates semantic words into visible actions, and returns the transformed room and visitor as a story.

## Current Scope

Document first. Then build a no-monster hybrid from the proven camera foundation and selected trailer mechanics.

## Non-Goals

- Generic trailer automation disconnected from the live room.
- Invisible cloud fallback for person detection.
- Replacing working exhibition behavior in one broad rewrite.
