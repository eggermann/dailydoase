# System Patterns
## Working Pattern
1. Plan the smallest useful slice.
2. Implement a separate capital-radius collection.
3. Run relevant checks and the requested collection.
4. Review generated outputs and changes.
5. Update memory and retrospective.
6. Do not commit without explicit permission.
## Quality Pattern
- Use 27 known EU capital coordinates and 100 km radius.
- Keep API keys out of output.
- Keep one copy of each story across overlapping zones.
- Sort articles by publication timestamp descending.
